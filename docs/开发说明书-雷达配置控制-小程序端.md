# 雷达配置控制 · 小程序端开发说明

## 页面结构

| 路径 | 说明 |
|------|------|
| `pages/radar-lab/index` | 控制台入口（赛事 / 场次维护 / 实时监控 / 战报） |
| `pages/radar-lab/oam/tournament-list` | 赛事列表（服务端） |
| `pages/radar-lab/oam/oam` | 场次列表（服务端） |
| `pages/radar-lab/oam/match-edit` | 场次新建/编辑 |
| `pages/radar-lab/oam/tournament-edit` | 赛事新建/编辑 |
| `pages/radar-lab/monitor/index` | **实时监控**：仅展示 `monitoring`（采集中）场次 |
| `pages/radar-lab/monitor/detail` | **单场监控**：曲线、绑定口令、关闭监控（无选场 UI） |
| `pages/radar-lab/poster/poster` | 影响力战报海报 |

## 交互要点

1. **场次列表「监控」** → `monitor/detail?match_id=`，只操作当前场次。
2. **实时监控** → 只读服务端进行中列表，点击进入单场详情；无搜索/选场。
3. **数据来源** → 全部走 `/api/app/*`，不使用本地 `Storage` 缓存。

## 依赖接口

详见 `docs/前端对接指南.md` 第十一节 **11.0 数据列表与详情**：

- `GET /api/app/tournament/list`
- `GET /api/app/match/list`（支持 `tournament_id`、`status` 过滤）
- `GET /api/app/match/detail`

写入仍用 `POST /api/app/oam/upsert`；监控操作用 `add_task`、`stop_monitoring`、`stream_data`。

## 权限

与「自动同步」相同白名单（`utils/sync-lab-whitelist.js` + `utils/radar-access.js`）。
